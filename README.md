# 开心软件市场

我自己写的软件攒了一些，散着发不方便，就弄了这个站点：一个前台给人下载，一个后台给我自己上架。

前台只能看到已经上架的应用；后台在另一个端口，上架、改资料、传图标和截图、传包体、下架、删除都在那里做。

## 跑起来

需要 Node.js 22.5 或更新版本（用到了内置的 `node:sqlite`）。没有别的依赖，不用 `npm install`。

```bash
npm start      # 正式启动
npm run dev    # 改代码自动重启
```

启动后终端会打印两个地址：

| 用途 | 默认端口 | 地址 |
| --- | --- | --- |
| 前台下载站 | 8080 | http://localhost:8080 |
| 后台管理台 | 8081 | http://localhost:8081 |

端口在根目录 `config.json` 里改，改完重启生效。后台端口不建议对外暴露。

## 数据放在哪

应用信息存在 `data/market.db`（SQLite），上传的图标、截图、包体存在 `uploads/` 下面。删应用的时候对应文件会一起删掉。这两个目录都是运行时自动建的，可以直接备份或整个搬走。

## 上架一个应用

后台点「新建应用」，填名字（必填）、包名、版本、开发者、分类、简介和介绍，然后：

- 图标：一张方图
- 截图：可以传多张
- 包体：APK / IPA / EXE / ZIP 都行，单个文件默认上限 800MB
- 开源链接：如果这个软件是开源的，把仓库地址填上，可以填多条。前台详情页会列出来，留空就不显示

没有包体的应用不能上架，这是有意为之——前台点下载却拿不到东西体验太差。

## 关于上传

文件不走 multipart，请求体直接就是文件本身，原始文件名放在 `x-file-name` 头里。所以服务端一个第三方解析库都不需要。

下载接口支持 `Range`，可以断点续传；只有完整下载才会加下载次数。`/uploads/packages/` 在前台端口是被拦掉的，包体只能通过下载接口拿到。

## 目录

```
开心软件市场/
├── config.json            端口和站点配置
├── server.js              入口，同时拉起前后台两个端口
├── src/
│   ├── config.js          配置、路径、上传体积上限
│   ├── db.js              SQLite 数据层
│   ├── util.js            响应、二进制上传、静态文件与 Range
│   ├── public-server.js   前台服务
│   └── admin-server.js    后台服务
├── shared/                前后台共用的样式和工具
├── public/                前台页面
├── admin/                 后台页面
├── docs/API.md            接口文档
├── uploads/               上传的文件
└── data/market.db         数据库
```
